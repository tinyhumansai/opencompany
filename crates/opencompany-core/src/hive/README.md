# `src/hive/`

Hive desks: one `OpenHumanHive` + `CompletionDriver` per `[[group_chat]]`
over the process-wide `openhuman_embed::Runtime`. The spec is
`docs/spec/runtime/hive.md`; this folder is its implementation, one seam per
file.

| File | What lives there |
| --- | --- |
| `mod.rs` | Index only. |
| `jev.rs` / `jev_tests.rs` | `TinyHumansSystemOne`, the `SystemOneTransport` over the TinyHumans System One proxy (`OPENCOMPANY_JEV_URL`), and `jev_router`, which answers `None` without a TinyHumans key so the driver routes by lead and mention. Gated on `openhuman`. |
| `mcp_server.rs`, `mcp_server/handler.rs` / `mcp_server_tests.rs` | The `opencompany` MCP server (`McpHost`): JSON-RPC over Streamable HTTP at `POST /internal/mcp/{company}/{runtime_agent_id}` on a dedicated loopback listener, one bearer per agent, `tools/list` = the speech tools plus the agent's OpenCompany tools, `tools/call` decided by the agent's `ApprovalPolicy`. `attach_opencompany_mcp` fixes it on an `AgentSpec`; `mount` puts the route on a caller's router. Gated on `openhuman`. |
| `tools.rs` / `tools_tests.rs` | `InFlightRegistry` — one in-flight turn per agent, keyed by runtime agent id — the `InFlight` speech fold (`speech::interpret`, one action per turn, `dm` recipient check), `InFlightContext` (the `ToolRunContext` a served tool runs under) and `McpToolAdapter`. Gated on `openhuman`. |
| `routing.rs` / `routing_tests.rs` | The `[group_chat.routing]` block (`RoutingConfig`, `ReferralConfig`), its resolution to tinyhivemind's `RoutingPolicy` / `ReferralPolicy` (`EffectiveRouting`, defaults `round_width=5`, `choice_option_limit=8`, `max_rounds=12`, `turn_timeout_secs=600`), the overlay precedence (`effective_routing`), and the wire shapes `RoutingPlanDto`, `DeskRoutingDto`, `DeskRoutingSummaryDto`, `Router`. Default build. |
| `episode_store.rs` / `episode_store_tests.rs` | The journal as the episode store: `fold_episodes` / `list_episodes` behind `GET {scope}/episodes`, the `EpisodeStateSaved` checkpoint (`PersistedEpisode`, `save_state`, `latest_state`), `replies_after` for a resume's replay, `episode_rows` for the rows a resumed host recalls, the `waiting` seats folded from `EpisodeSeatParked` / `EpisodeSeatResumed`, and `open_episode_for` — the `(desk, thread)` key a follow-up joins. Default build. |
| `session_log.rs` / `session_log_tests.rs` | `EventLogSessionLog`: the company journal read as a tinyhivemind `SessionLog`, one desk at a time, with attributed authors (operator / agent / system). Moved from `src/hivemind/log.rs`. Default build. |
| `referral.rs` / `referral_tests.rs` | Cross-desk referral, read side: `HIVE_REFERRAL_AUTHOR` and the legacy report authors a history projection drops, `pair_conversation` / `pair_seats` (the `dm:<a>+<b>` key), the attribution heads a question and its answer carry (`asked_message`, `returned_note`, `unattributed`), and `ReturnAddress`, the serde shape a far episode's checkpoint keeps. Default build. |
| `graph.rs` / `graph_tests.rs` | `DeskHive` and `desk_hives`: one validated `OpenHumanHive` per desk of two or more bound seats, over the pool's live `openhuman_embed::Agent` handles — a shared agent is the same handle in every hive that lists it. Gated on `openhuman`. |
| `conducted.rs` | One completion episode on `tinyhivemind`'s own loop: `run` / `resume` build the door, seat each teammate and hand the episode to the library; `HiveDispatcher` holds one company's desks, journal and router for the brain to open an episode on. Gated on `openhuman`. |
| `host.rs` / `host_tests.rs`, `host_mentions_tests.rs` | `DeskHost`, this company as the host of one episode: the journal the episode reads and commits through, and how a teammate is built as a seat with the episode's tools on its belt; `SeatParking` parks a seat on an approval. Gated on `openhuman`. |
| `seating.rs` / `seating_tests.rs` | `EpisodeBelts`: the tools an episode lends a teammate (`SeatLoan`, `TakeoverLoan`), keyed by the conversation its seat runs in, so the agent's belt factory finds them when that turn arrives. Gated on `openhuman`. |
| `takeover.rs` / `takeover_tests.rs` | `take_over`: a guest seat concludes the conversation that asked it through the room's `complete_episode`, then announces the claim in its own line (`TakeOverTool`, `TakeoverQueue`). Gated on `openhuman`. |
| `shared_tool.rs` / `shared_tool_tests.rs` | `SharedTool`: a shared `Arc<dyn Tool>` handed out as an owned belt entry per turn, forwarding every trait method. Gated on `openhuman`. |
| `measure.rs` / `measure_tests.rs` | The coordination fold behind `opencompany measure`: turn brackets to the concurrency peak and same-agent overlaps, episode frames to rounds / reasons / time to complete, `BroadcastRouted` / `DmDelivered` / `ReferralEnqueued` to contacts and pairs, `AgentReply.episode.kind` to the utterance histogram; `Thresholds` mirror `scripts/lib/coordination-metrics.mjs`. Default build. |
| `dispatch.rs` | The brain's chat body: `surface_of` (a desk with a hive is a `Room`, everything else `Single`), `hives_for`, `host_router`, `dispatcher`, `spawn_episode`, `spawn_resume`. Gated on `openhuman`. |
| `host/seat_park.rs` / `host/seat_park_tests.rs` | A seat turn's claims and park: `SeatQueues` / `SeatClaims` scope a seat's approvals, publishes and outputs to its own turn, `EpisodeSeatParking` parks what it asked under the `episode-seat:{episode}:{seat}` turn key, and the decision the runtime hands back through `EpisodeReleases` is written to the seat before it runs again. Gated on `openhuman`. |
| `host/delivery.rs` / `host/delivery_tests.rs` | What a seat turn hands over: its publishes are filed on a card minted for the room (`PublishDestination::Episode`, through `HarnessDeps::record_conversation_publishes`), and its outputs and that card ride its next desk row, or an outputs-only row once its wave has committed everything it will. Gated on `openhuman`. |
| `test_support.rs` | `MemoryLog` and row builders for the hive tests. Test-only. |
