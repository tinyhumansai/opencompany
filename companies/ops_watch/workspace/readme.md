# Ops workspace

The team's shared, Obsidian-style workspace — this company's **template
workspace**, the starter notes every new instance begins with. Organize in
folders, write in Markdown, link notes with `[[wiki links]]`.

Start here:

- [[How the hourly run works]] — what happens every hour, and what does not
- [[What to do first]] — the runbook, one entry per threshold
- [[What this cannot see]] — the blind spots, written down rather than discovered

Everything here is a plain `.md` file, so it version-controls cleanly and seeds
the operator console's Workspace view.

The runbook is the note that earns this company its keep. A finding that says
what is wrong and nothing about what to do is a page at 3am that makes someone
open a terminal to start from scratch.
